Área privada

Cada voluntário acompanha horas, agenda e certificados.

O que se pede

  • Só para usuários autenticados
  • Acesso protegido

Rotas privadas · exigem sessão

  • /painelMeu painelbanco de horas, inscrições e próximas atividades
  • /minhas-atividadesAgenda e inscriçõescalendário e cancelamento com confirmação
  • /certificadosMeus certificadosregistro, histórico e download
  • /organizacaoGestão de atividadespapel organizaçãopresença e envio de certificados

Como é protegida

  • Barrada antes de abrir: as quatro rotas estão no matcher do proxy (requisito 05)
  • Conferida de novo no servidor: a própria página exige a sessão antes de buscar dados

Do clique à sessão

  1. 1

    Formulário validado. React Hook Form + Zod exigem e-mail válido e senha com 6 ou mais caracteres; o erro aparece no próprio campo.

  2. 2

    POST /api/auth/login. O servidor valida de novo com o mesmo schema, confere a senha (hash scrypt) e limita tentativas.

  3. 3

    Sessão em cookie HttpOnly. Token assinado (HMAC-SHA256) válido por 8 h, que o JavaScript da página não consegue ler.

  4. 4

    Volta para onde parou. Segue para o ?next (só caminhos internos) ou para o /painel.

Sair: diálogo de confirmação e sessão revogada no servidor.

05

Requisito 5 de 5

Controle de acesso

src/proxy.ts decide, antes da página, quem pode entrar.

O que se pede

  • Verificar se está autenticado
  • Permitir ou bloquear rotas privadas
  • Redirecionar ao login
src/proxy.ts 
export async function proxy(request: NextRequest) {
  const user = await verifySessionToken(                  1
    request.cookies.get(SESSION_COOKIE_NAME)?.value);
  if (user) {                                             2
    if (request.nextUrl.pathname.startsWith("/organizacao")
        && user.role !== "organization") {
      return NextResponse.redirect(new URL("/painel", request.url));
    }
    return NextResponse.next();
  }
  const loginUrl = new URL("/entrar", request.url);       3
  loginUrl.searchParams.set("next",
    `${request.nextUrl.pathname}${request.nextUrl.search}`);
  return NextResponse.redirect(loginUrl);
}

export const config = {                                   4
  matcher: ["/painel/:path*", "/organizacao/:path*",
    "/certificados/:path*", "/minhas-atividades/:path*"],
};
  1. 1

    Verifica se está autenticado. Lê o cookie e confere assinatura, validade e se a sessão não foi revogada.

  2. 2

    Permite ou bloqueia. Sessão válida segue com next(); voluntário em /organizacao volta ao painel.

  3. 3

    Redireciona ao login. Sem sessão, vai para /entrar guardando o destino em ?next.

  4. 4

    Define o que é privado. O matcher lista as rotas protegidas; as públicas nem passam aqui.

No Next.js 16, o antigo middleware.ts passou a se chamar proxy.ts.
